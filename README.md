# 人脸识别归档图形化工具（face-match-tool）

> 本地离线运行的「照片 / 视频人脸识别归档」工具。从杂乱的相册里把**含特定人物的**图片和视频挑出来，按相似度分档、按拍摄时间重命名，集中到一处。

**特点**：纯本地、离线、不上传任何数据；无需 GPU；带图形界面，小白也能用。

> 典型场景：家庭相册（尤其是微信保存的图片视频、手机相册备份）里混着大量他人照片、截图、表情包，本工具帮你把**某一个人**（默认是家里的孩子）出现过的素材自动筛选出来。

---

## 一、项目简介

工具做三件事：

1. **建立特征模板**：从你提供的「参考样本」（该人物的清晰照片/视频）提取面部特征，生成目标人物的特征模板。
2. **全量扫描打分**：遍历「待整理相册」，对每张图片 / 每段视频抽帧，计算与目标人物的相似度（0~100 分），产出评分报告。
3. **分档归档**：把达到门槛的文件按相似度**每 10% 建一个文件夹**，并重命名为「拍摄时间 + 相似度 + 原名」。

设计上把「识别打分」和「文件搬运」拆成两个独立阶段：**先只看报告、确认阈值，再执行搬运**，避免一上来就把几万个文件复制错。扫描阶段对源文件**只读**，绝不修改或复制。

---

## 二、功能特性

- 🖥️ **图形化界面**：浏览器里选目录、调参数、看实时进度和分档直方图，无需敲命令。
- 🔒 **完全离线**：不联网、不上传数据，所有处理在本机完成。
- ⚡ **免 GPU**：纯 CPU 推理，普通电脑即可运行。
- 🎞️ **视频支持**：按毫秒间隔抽帧检索，视频整体分数取各帧最高分。
- 🔗 **图片-视频配对**：同名封面图达标时，对应视频免抽帧（实测可省约 25% 时间）。
- 🗂️ **按相似度分档**：每 10% 一个文件夹（00-10、10-20 … 90-100）。
- 🕒 **按拍摄时间重命名**：优先 EXIF / 视频元数据，自动降级到文件时间。
- 🪢 **硬链接优先归档**：同一分区内秒级完成、几乎不占额外空间（跨盘自动回退为复制）。
- 📄 **断点续扫**：中间结果落 SQLite，崩溃或中断后重跑自动跳过已处理文件。
- 🧰 **缩略图过滤**：自动跳过 `_thumb` 等缩略图，扫描量可降九成以上。
- 🌐 **跨平台**：同一套代码可在 Windows / Linux 上运行。

## 三、运行环境与前置条件

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 10+（也支持 Linux） |
| Python | 3.12（需自行安装依赖，见下方「源码运行」） |
| 核心依赖 | `insightface` 2.1、`onnxruntime`(CPU)、`opencv-python` 5.0、`fastapi`、`uvicorn`、`numpy`、`Pillow`、`scipy` 等（见 `requirements.txt`） |
| 人脸识别模型 | `buffalo_l`（RetinaFace + ArcFace，约 281 MB），首次运行自动下载到 `~/.insightface/models/` |
| ffprobe（可选） | 用于读取视频**真实拍摄时间**；没有也能跑，视频时间会降级为文件修改时间。把 `ffprobe.exe` 放进 `_vendor/` 目录即可，无需安装系统 ffmpeg |
| 性能参考 | 纯 CPU 推理；12 核机器全量数百文件约 10 分钟量级，超大批量建议分批 |

> 💡 **不想装 Python / 依赖？** 直接使用项目附带的**绿色版**（文件夹名 `人脸识别归档图形化工具绿色版/`）：里面自带 Python 运行环境、buffalo_l 模型和启动器，**解压后双击 `启动工具.bat` 即可使用，免安装、免联网**。

## 四、如何运行

### 方式一：绿色版（推荐，免安装）

1. 把 `人脸识别归档图形化工具绿色版/` 整个文件夹拷贝到任意位置（建议路径不含中文/空格）。
2. 双击 `启动工具.bat`。
3. 浏览器自动打开 `http://127.0.0.1:8777/` ，按界面提示选择三个目录即可开始。

### 方式二：源码运行

```bash
# 1. 安装依赖
pip install -r requirements.txt
# 处理 iPhone 的 HEIC 照片（可选）：
pip install pillow-heif

# 2. 启动图形界面（会自动开浏览器）
python webui.py
# 或双击 start-ui.bat
```

启动后访问 `http://127.0.0.1:8777/`。

### 图形界面操作步骤

1. 选择 **参考样本目录**（目标人物的清晰照片/视频，建议 10~30 张、覆盖不同场景/年龄）。
2. 选择 **待整理相册目录**（要全量筛查的素材）。
3. 选择 **输出目录**（默认与程序同级的 `归档输出`）。
4. 点「开始扫描」，查看分档直方图与高分清单，**确认阈值合适**。
5. 点「开始归档」，文件即按相似度分档、按时间重命名到输出目录。

### 命令行方式（可选，适合批量 / 服务器）

```bash
# 第 1 步：先小样本试跑，确认阈值（--limit 限制文件数）
python scan.py --ref "D:\照片\参考样本" --src "D:\照片\相册" --out "D:\照片\_out" --limit 200

# 打开 _out/scan_report.csv，按 score 列确认分数线落在哪里

# 第 2 步：正式扫描
python scan.py --ref "D:\照片\参考样本" --src "D:\照片\相册" --out "D:\照片\_out"

# 第 3 步：预览归档（不落盘，先看会归档哪些）
python archive.py --out "D:\照片\_out" --dry-run

# 确认无误后实际搬运
python archive.py --out "D:\照片\_out"
```

## 五、输出结构

```
_out/
├── dataset/                # 最终成果，按相似度分档
│   ├── 90-100/
│   ├── 80-90/
│   └── 70-80/              # 低于收录门槛的不出现
├── scan_report.csv         # 全量评分报告（含余弦原始值、时间来源等）
├── reference_samples.csv   # 参考样本采纳明细
├── archive_report.csv      # 归档搬运明细
└── _state.db               # 断点续跑状态库
```

默认文件名格式：`{日期}_{时间}__s{相似度}__{原名}.{扩展名}`，可在 `config.yaml` 的 `archive.naming` 调整（支持 `{date}` `{time}` `{score}` `{bin}` `{stem}` `{ext}`）。

## 六、常用配置

改 `config.yaml` 即可，**图形界面里点「重新载入」按钮即时生效，无需重启服务**：

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `bins.min_score` | 30 | 收录门槛，低于此分数不归档（对应余弦约 0.62）。**60 分以下建议人工复核** |
| `similarity.calib_low` / `calib_high` | 0.50 / 0.90 | 余弦→百分数的线性映射区间，需用真实数据标定 |
| `runtime.workers` × `model.intra_op_num_threads` | 3 × 2 | 并行配置，乘积约等于 CPU 逻辑核数（**不是越多越快**） |
| `scan.exclude_patterns` | `["_thumb"]` | 跳过缩略图等，**通常是最有效的提速手段** |
| `scan.pairing.enabled` / `reuse_min_score` | true / 70 | 图片-视频配对，封面图达标则视频免抽帧 |
| `scan.video.frame_interval_ms` | 500 | 视频抽帧间隔，越小越密、越不易漏，但耗时线性上升 |

> ⚠️ **儿童人脸精度天然低于成人**，建议把 70~90 分区间当作「需人工确认」的缓冲区；标定参数（`calib_*`）务必用自己的照片重新标定，不要直接套用默认值。

## 七、工作原理（简略）

1. **特征提取**：用 `insightface` 的 `buffalo_l` 模型——RetinaFace 做人脸检测与对齐，ArcFace 提取 512 维特征向量。从参考样本的多张人脸取平均，构建目标人物的**特征模板**（并自动剔除离群样本）。
2. **相似度计算**：对待整理素材逐张 / 逐帧抽取人脸特征，与模板计算**余弦相似度**。
3. **分数映射**：ArcFace 余弦分布很窄（同人大约 0.5~0.9，异人 0.0~0.4），直接乘 100 会全挤在 50~90 分。工具用 `calibrated` 模式把有效区间线性拉伸到 0~100 分，让十个分档有区分度。
4. **分档与归档**：按分数每 10% 建文件夹；文件名采用拍摄时间（EXIF / 视频元数据优先，逐级降级），用硬链接或复制落到输出目录。
5. **视频处理**：按间隔抽帧，整体分取各帧最高分；若同名封面图已达标，则整段视频免抽帧（这一推断只会低估、不会漏检）。

---

## 八、已知限制

- 儿童人脸精度低于成人，低分区间需人工复核。
- 纯 CPU 推理，超大批量（十万级）建议分批或换更强机器。
- 硬链接仅在同一磁盘分区有效，跨盘自动回退为复制。
- 输出目录不要与源目录放在同一目录树，避免下次扫描重复计入。
